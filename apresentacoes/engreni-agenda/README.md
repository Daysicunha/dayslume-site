# ENGRENI Agenda — Apresentação Comercial

Site estático e independente do sistema de agendamento usado por clientes. Toda a experiência é demonstrativa, sem banco ou acesso a dados reais.

## Publicação na Vercel

- Nome de projeto: `engreni-agenda-apresentacao`
- Repositório: `Daysicunha/dayslume-site`
- Root Directory: `apresentacoes/engreni-agenda`
- Framework Preset: Other (static HTML)
- Código desta versão está na branch: `feat/apresentacao-comercial-engreni-agenda-20261030`
- Atenção: não promover a `main` do site DAYSLUME por engano. Para um projeto independente e manutenção facilitada, recomenda-se depois extrair esta pasta para um repositório exclusivo.

## Privacidade e alcance

- Agendamentos, faltas e bloqueios são simulações locais no navegador.
- Não grava dados pessoais nem altera o sistema ENGRENI Agenda real.
- O botão de interesse abre o WhatsApp comercial DAYSLUME.
- `noindex` permanece ativado até homologação da apresentação pública.
- Valores comerciais são deliberadamente omitidos até definição da proposta.
